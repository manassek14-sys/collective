Modes de paiement

Les membres peuvent vous envoyer leurs cotisations via les canaux que vous avez configurés dans l’espace. Vous renseignez vos propres numéros (protégés par mot de passe).

MTN

Mobile Money

Recevez via MTN MoMo. Affichez votre numéro et le nom du titulaire.

ATL

Airtel Money

Idéal pour les membres sur le réseau Airtel.

OM

Orange Money

Canal Orange Money pour encaisser rapidement.

VISA

Visa / Banque

Compte, IBAN ou référence carte pour les virements.

Comment ça fonctionne ? Ce n’est pas une passerelle de paiement automatique (pas de bouton « payer maintenant » relié à la banque). Vous configurez vos coordonnées dans l’app ; les membres voient où envoyer l’argent, puis vous validez la cotisation dans COLLECTIVE.
